# Visual Exam Simulator

aqui estão questões sobre sistema visual, quero que você faça um banco de dados com ela, classificando-as em "médias", "fáceis" e "difíceis" e crie um html com um site basico com uma interface que atua como "simulador de prova", coloque 20 questões sendo q elas vão ser um sorteio das 50. também coloque na tela de iniciar a prova uma interface que permite escolher assuntos (como só existe o visual somente ele estará disponível, além de "todos"), e faça um sistema de cores vermelha e verde na opção caso o usuario acertar ou errar
